# Southern Breeze HVAC Repairs — Emergency AC Repair Landing Page

Single-page, mobile-first site built to out-convert an Angi / BBB / YellowPages / Facebook listing:
one job, one page, one tap to a ringing phone.

**Primary phone:** (228) 255-9190 · **Service area:** Diamondhead, Kiln, Bay St. Louis & Hancock County, MS · **Hours:** 24/7

Stack: **Next.js 14 (App Router) + Tailwind CSS**, zero images, zero webfonts, deployable to Vercel as-is.

---

## The conversion path (in order of priority)

| Priority | Element | Where |
| --- | --- | --- |
| 1 | **Sticky bottom call bar** — always on screen, `tel:` link, survives every scroll position | `app/components/StickyCallBar.jsx` |
| 2 | **Hero tap-to-call button** — full width, 56px tall, cyan, above the fold with no scrolling | `app/page.jsx` → `Hero` |
| 3 | Phone number as a tappable `tel:` link everywhere it appears (hero, header, services band, service area, request section, form, FAQ answer, final CTA, footer) | all sections |
| 4 | **Request-service form** (name, phone, service, urgency) for people who will not call yet | `app/components/RequestForm.jsx` |
| 5 | Trust bar directly under the hero: licensed/insured · 24/7 + ~45-min avg response · 4.6★ / 38 reviews · 14 yrs local | `TrustBar` |

Above-the-fold contents (verified against a 375×667 viewport): brand name, value prop, live "answering now"
badge, tappable phone number, and the primary CTA — a visitor can call without scrolling.

## Speed

- No photographic assets, no carousel, no autoplay video, no icon library — every icon is inline SVG on
  `currentColor` (`app/components/icons.jsx`).
- System font stack only: no webfont request, no FOIT/FOUT.
- One CSS file, one small client component (the form); everything else is a server component.
- FAQ uses native `<details>` — zero JS for the accordion.
- `prefers-reduced-motion` respected for the hero pulse and smooth scrolling.

## Deploy

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

On Vercel: import the repo, framework auto-detects Next.js, then add the env vars below and deploy.
No build settings or overrides needed.

### Environment variables

| Key | Required | Notes |
| --- | --- | --- |
| `SUPABASE_URL` | recommended | Supabase project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | recommended | server-side only; bypasses RLS for lead inserts |
| `NEXT_PUBLIC_SITE_URL` | recommended | real domain, used for canonical URL, sitemap, JSON-LD |

If the Supabase keys are missing, `POST /api/request-service` returns `{ ok: false, error: "not_configured" }`,
the form logs the lead server-side, and the visitor is shown **"calling is faster"** with the phone number —
a lead is never silently swallowed.

### Where form leads go

Table `public.service_requests` in Supabase (created for this project):

`id · created_at · name · phone · service · urgency · city · notes · source · user_agent`

RLS is enabled with no public policies, so only the server (service role key) can write or read.
To get notified instantly, add a Supabase **Database Webhook** on `service_requests` INSERT → email/SMS/Twilio,
or point a Zapier/Make catch hook at the same table. A saved lead nobody sees is a lost job.

## Things to confirm / change before it goes live

1. **`NEXT_PUBLIC_SITE_URL`** is currently the placeholder `https://southern-breeze-hvac.vercel.app`. Set the real
   domain in Vercel; it feeds the canonical tag, sitemap and JSON-LD.
2. **ZIP codes** — Diamondhead 39525, Kiln 39556, Bay St. Louis 39520 are used in the service-area section.
   Confirm them for the exact service footprint. Waveland (39576) is also in Hancock County and is an easy add
   to `SITE.cities` in `lib/site.js` if it is served.
3. **`priceRange: "$$"`** in the JSON-LD is a placeholder. Replace with the real directory-style range, or delete
   the field.
4. **Diagnostic fee wording** — the FAQ says a diagnostic charge applies and is quoted up front. If the diagnostic
   is free (or a fixed dollar amount), update `FAQS` in `lib/site.js`.
5. **Address** — JSON-LD intentionally contains only city/state/ZIP (no street address was provided). Add
   `streetAddress` and `geo` coordinates once confirmed; a verified Google Business Profile with matching NAP is
   the single highest-leverage local SEO move here.
6. Heading/CTA copy and all business facts live in one file, **`lib/site.js`** — edit there and the UI, the
   structured data, and the meta description all update together.

## Editing content

`lib/site.js` holds phone, hours, years, rating, cities, services, testimonials and FAQs. `app/page.jsx` renders
sections in this order: Hero → Trust bar → Services → Service area → Reviews → Request service → FAQ → Final CTA
→ Footer. Anchors: `#services`, `#area`, `#reviews`, `#request`, `#faq`.
